Multi-Modal RAG with PDFs

Building retrieval systems that handle text, tables, and images in PDF documents — challenges, solutions, and production patterns.

  • Embedding generation

Core Challenges
  • Text: Scanned PDFs, multi-column layouts, headers/footers
  • Tables: Structure collapse, merged cells, multi-page spanning
  • Images: Complete blindness to charts, diagrams, infographics
  • Chunking: Fixed-size splits destroying context
  • Embeddings: Semantic mismatches, multilingual gaps
  • LLM: Hallucinations, lost-in-middle, citation errors
🔄 The Three-Track Architecture
Parallel pipelines for different content types
Track 1: Text Pipeline
  • Extract: pdf-parse + OCR fallback
  • Clean: strip headers/footers
  • Chunk: semantic chunking
  • Embed: text-embedding-3-large
  • Index: dense + sparse
  • Retrieve: hybrid RRF + rerank
Track 2: Table Pipeline
  • Detect: tabula-js + layout
  • Reconstruct: merge multi-page
  • Represent: Markdown + NL summary
  • Embed: both representations
  • Index: separate table index
  • Retrieve: query-routed retrieval
Track 3: Image Pipeline
  • Extract: render pages as PNG
  • Describe: Vision LLM captions
  • Embed: CLIP + caption embeddings
  • Index: multi-modal vectors
  • Retrieve: text-to-image search
  • Return: images with captions
⚙️ Key Solutions
What breaks in naive RAG and how to fix it
Scanned PDFs
  • Returns garbled/empty text
  • No content extraction
Solution
  • OCR with layout analysis
  • AWS Textract / tesseract.js
Table Structures
  • Flattened to text stream
  • Row/column mapping lost
Solution
  • Structured extraction to Markdown/HTML
  • Natural language summary chunk
Images & Charts
  • Completely ignored
  • No visual information indexed
Solution
  • Vision LLM generates captions
  • CLIP embeddings for visual search
Fixed-Size Chunking
  • Splits mid-sentence
  • Context destroyed
Solution
  • Semantic chunking on boundaries
  • Embedding similarity scoring
Domain-Specific Terms
  • General embeddings miss jargon
  • Poor retrieval on specialized vocab
Solution
  • Fine-tuned domain models
  • Hybrid BM25 retrieval
Lost-in-the-Middle
  • LLM ignores middle chunks
  • Context window issues
Solution
  • Cross-encoder reranking
  • Relevance-ordered formatting
🧪 Edge Cases to Handle
Production scenarios most tutorials skip
HIGH
Password-Protected PDFs
Detection & user password prompt needed or graceful skip with logging
HIGH
Multi-Page Tables
Header row on page 1, orphaned data rows on later pages — must reassemble
HIGH
Mixed Languages
English + German + French in one doc — multilingual embeddings required
HIGH
Tables as Images
Excel screenshots pasted as PNG — OCR + vision model needed
MED
Duplicate Versions
v1 & v2 both indexed with conflicting data — content-hash dedup
MED
Rotated Pages
90° landscape tables on portrait pages — rotation detection needed
MED
Conflicting Figures
Executive summary vs appendix disagree — surface conflicts with sources
MED
Time-Sensitive Data
Old reports still indexed — attach doc dates & warn on staleness
MED
Math Equations
LaTeX/MathML as images — content lost without OCR or equation parsing
MED
Legal Boilerplate
60+ pages of identical disclaimers — dedup or exclude sections
LOW
Embedded PDFs
PDFs nested inside other PDFs — standard parsers miss inner docs
LOW
Handwritten Notes
Margin annotations in scanned docs — handwriting-specific models needed
LOW
Watermarks
Semi-transparent overlays degrade OCR accuracy on underlying text
LOW
Cross-Doc References
"See Report B" — referenced doc missing from corpus
LOW
Form Fields
Filled AcroFields stored separately — standard extraction misses form data
LOW
Invisible Text Layers
OCR-generated PDFs with hidden text behind images
