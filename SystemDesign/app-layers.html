OSI Model 7 Layers — where they fit in system design ▼
The OSI model describes how data travels across a network. In system design, layers L1–L3 are managed by cloud infrastructure, L4 is where transport-level load balancing happens, L6 handles encryption, and L7 is where your application protocols (HTTP, gRPC, WebSocket) live.
Layer Name Role in System Design Key Protocols / Tech Example Tools / Concepts System Design Layer
L1 Physical Transmission of raw bits over physical medium. Managed entirely by cloud providers — invisible to application engineers. Ethernet Fiber Wi-Fi Coaxial AWS/GCP data center hardware, NICs, cables — abstracted away Infrastructure
L2 Data Link Node-to-node data transfer using MAC addresses. Relevant when configuring VLANs, network switches, or virtual NICs in cloud networking. Ethernet frames MAC addresses ARP VLANs Network switches Virtual NICs Cloud security groups (L2 rules) Infrastructure
L3 Network Logical addressing and routing between networks. This is where VPCs, subnets, IP routing tables, and NAT gateways operate. IP (v4/v6) ICMP BGP OSPF NAT VPC Subnets IP routing tables NAT Gateway Internet Gateway Infrastructure
L4 Transport End-to-end communication using ports. L4 load balancers operate here — routing TCP/UDP packets without inspecting the payload. Also where connection pooling and TCP tuning matter. TCP UDP SCTP Ports L4 Load Balancer (AWS NLB) Connection pooling TCP keep-alive UDP (DNS, QUIC) Infrastructure Backend
L5 Session Manages sessions between connections. In practice, rarely referenced independently — TLS session management and SSH tunnels are the most relevant system design touchpoints. TLS session SSH NetBIOS RPC TLS session resumption SSH tunnels Session tokens (overlap with L7) Infrastructure
L6 Presentation Data translation, encryption, and compression. TLS/SSL lives here — this is where HTTPS encryption and decryption happens. Also data serialization (JSON, Protobuf, gzip). TLS / SSL gzip / brotli JSON / XML Protobuf Base64 TLS Termination HTTPS gzip compression Protobuf serialization Infrastructure Cross-Cutting (Security)
L7 Application The protocol your application speaks. L7 load balancers route by URL path, headers, or cookies. REST, GraphQL, gRPC, WebSockets, DNS all live here — this is where most backend and frontend engineering happens. HTTP / HTTPS WebSocket gRPC DNS SMTP FTP QUIC L7 Load Balancer (AWS ALB) API Gateway REST / GraphQL / gRPC Browser HTTP client DNS resolution Backend Frontend Infrastructure
